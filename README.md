# Calculator

A simple calculator built with **HTML**, **CSS**, and **JavaScript**.

This project allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. It also includes a button for brackets, decimal input, clearing the screen, deleting the last character, and displaying the answer.

## Features

* Basic arithmetic operations
* Bracket support
* Delete last character button
* Clear screen button
* Responsive layout
* Styled calculator interface
* Display that scrolls horizontally when the input gets longer

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

The calculator uses JavaScript to:

1. Capture button clicks
2. Add values to the screen
3. Remove the last character
4. Clear the display
5. Evaluate the expression and show the result

The `eval()` function is used to calculate the final answer.
